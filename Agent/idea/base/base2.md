- 一轮循环到底发生了什么

while () {
    1. 准备上下文   --- （
        检查上下文爆了吗，快爆了就压缩 -- 
            1. snip删掉旧的消息，2. Microcompact局部摘要，3. Auto-compact全局摘要）

    2. 调用模型 API  --- (模型流式返回，还在输出中，已经识别到的工具函数就要开始执行)
        边说边执行 -- 只有不冲突的操作才能并行

    3. 决定是否继续  --- （claudeCode： 7种退出条件）
        1. 模型没有工具调用
        2. 流式传输被中断
        3. 工具执行被中断
        4. hook阻止了继续执行
        5. 超过了最大轮数
        6. 上下文过长，API拒绝
        7. 压缩后上下文还是过长，无法恢复

    4. 执行工具 --- （工具函数如果报错，错误信息就要写的足够优雅）

    5. 构建下一轮状态  --- 开始下一轮之前，处理一些杂活： 检查skill，记录已消费的命令...
}


# 状态追踪
1. 现在到第几轮了？ 用来判断是不是该停下 （保险丝）
2. 上一轮为什么选择了继续？（上一轮可能正常，也可能是错误恢复，也可能是压缩重试）
3. 压缩执行哪了？（是否触发紧急压缩，压缩后token下降多少）
4. 输出被截停了多少次？ （模型输出到一半被截停，一次恢复，两次恢复，三次就放弃）
5. 有没有被挂起的任务？ （）
