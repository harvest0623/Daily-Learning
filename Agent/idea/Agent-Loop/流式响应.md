# SSE （Server-Sent Events）  vs  WebSocket
- WebSocket 全双工通信，客户端很服务端建立连接后不释放，客户端可以随时发送消息给服务端，服务端也可以随时发送消息给客户端

- LLM的流式输出，本质上是服务端向客户端一个一个的推送token，这个过程，客户端是不需要向服务端发送消息的

- SSE：HTTP的一种特殊模式，客户端可以跟服务端建立一个长连接，服务端可以随时向客户端推送消息。SSE协议拥有重试机制，如果连接断开，客户端可以自动重连。

# claudeCode 的并发安全判断
1. Read文件：只读不写，可以并发
2. Glob/Grep：只搜索不修改，可以并发
3. Edit 文件： 写入操作，必须串行
4. Bash 命令： ls可以并发， rm必须串行

# 工具执行的结果按什么顺序返回？
claudeCode 会按工具调用的顺序返回结果，目的是为了保证工程的顺序性，可读性，方便调试
