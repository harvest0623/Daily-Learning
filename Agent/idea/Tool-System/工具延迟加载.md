# 一：claudeCode 工具 Deferred Tool Loading
- 两类工具会被延迟：
    1. MCP工具：因为所有通过MCP Server 接入的工具，都是用户自己装的
    2. 内置的工具：标记了 shouldDefer: true 的工具

## 延迟工具的发现机制
- 模型看到的工具不是完整的 schema，而是一个工具名字列表：
   "以下工具可用，但需要先通过 ToolSearch 来获取完整的 schema：WebSearch、WebFetch..."

2. 模糊匹配：用户输入 "搜索" 或 "获取" 等关键词，模型会根据上下文推断出用户可能需要的工具

# 二：OpenClaw 工具配置文件
将所有的工具函数按场景划分，比如：
1. minimal: 最基础的交互
2. Coding: 代码相关的操作
3. messaging: 通讯相关的操作
4. full：全部能力

# 三：小工具集 (Manus)
1. 原子工具：最基础的工具，比如读取文件、写入文件、发送HTTP请求等
2. CLI工具：通过 sendBox 来暴露 CLI 命令，比如 "git clone"、"npm install" 等
3. 写脚本: 复杂的逻辑现场让模型用 python或者nodejs 写脚本
