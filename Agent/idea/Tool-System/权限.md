# 生产级系统权限 四层防线
- 怎么设计一个即安全，有不烦人的权限系统
    1. 高频安全操作默认放行
    2. 低频的危险操作要拦下来

# claudeCode 权限系统
- 四种权限模式
    1. plan           只会做读取，搜索不会写入    设计方案阶段
    2. default        自动允许读取，但是写入操作要被确认   日常开发
    3. acceptEdits    文件编辑是自动允许的，但是Bash仍要确认   信任模型改代码，不信任它执行命令
    4. bypassPermissions  绕过所有的权限检查，完全放权   测试环境（沙箱环境）

- 除了全局模式，claudeCode 还支持细粒度的权限规则
    1. 可以针对每个工具和参数设置权限
