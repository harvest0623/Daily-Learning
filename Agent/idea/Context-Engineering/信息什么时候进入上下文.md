# 全量预填充
不管三七二十一，将Agent循环过程中的到的所有信息全部填充到上下文。

# JIT （Just-in-time）按需加载
在Agent循环过程中，不提前塞入内容，等Agent真正需要某段信息时，再填充到上下文。

- RAG
- Agentic Search (运行时工具探索)
- Context Offloading （主动卸载 + 按需恢复）

- 按成本递增排序工具调用：先用最便宜的工具，再用稍贵的工具，最后用最贵的工具来获取更多细节
1. Glob -- 按文件名模式搜索，只返回路径，不读内容
2. Grep -- 按内容模式搜索，返回命中的行
3. Read -- 读有问题的那个文件
