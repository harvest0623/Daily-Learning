# 模型路由
1. 按任务类型，静态路由：xx类型的任务交给xx模型来干

2. 按难度，动态路由：需要设计一个分类器，根据用户当前的prompt来分析任务难度，简单任务交给便宜模型，复杂任务交给贵一点的模型
