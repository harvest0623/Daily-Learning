# PyTorch
一个深度学习框架，提供了张量计算，和 自动求导等功能。
张量  = 多维数组， 是 PyTorch 的核心数据结构。
张量可以自动计算梯度，并支持GPU加速

1. 是一个张量计算库
2. 是一个自动微分引擎 （自动求导）
3. 是一个深度学习框架 （可以构建神经网络结构）

# mini-transformer
- 核心就是注意力机制
1. 初始化模型
2. 向量化输入 + 位置编码
3. 经过 N 层 Transformer Block （每个 Block 包含注意力机制和 FFN）--- 每一个向量都进行注意力机制和 FFN 操作
4. 最终层归一化 （先算点积， 再算权重， 最后加权求和）
5. 输出头 
6. 生成测试
